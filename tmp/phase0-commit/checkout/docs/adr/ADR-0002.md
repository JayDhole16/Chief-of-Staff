# ADR-0002: Founder-confirmed authority

Status: **Proposed / pending team review**. Prepared: 2026-10-14 IST.

Context: Capture the existing workbook decision for the three-person implementation; this record does not certify current code.

Decision: **Authority comes only from a founder-confirmed, time-boxed mandate with typed clauses, or from an explicit approval.** Default deny; one active mandate; confirm, approve, revoke and kill switch exist only in the founder API — never as agent tools.

Consequences: Preserve explainable, bounded autonomy. Any departure follows the reviewed ADR/schema/snapshot process; this session changes no implementation contract.
