# ADR-0005: Sealed credential isolation

Status: **Proposed / pending team review**. Prepared: 2026-10-14 IST.

Context: Capture the existing workbook decision for the three-person implementation; this record does not certify current code.

Decision: **Credential isolation:** Google refresh tokens are sealed with a public key in `api` and opened only in `worker`; `api` refuses the private key; access tokens never stored.

Consequences: Preserve the agent-facing process cannot act on Google. Any departure follows the reviewed ADR/schema/snapshot process; this session changes no implementation contract.
